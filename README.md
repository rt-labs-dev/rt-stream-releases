# RT Stream

Your own streaming service for the movies, shows and music you already have. A self-hosted media server for Windows, macOS and Linux.

**Download, how it works and privacy policy: [apps.rtobo.dev/rt-stream](https://apps.rtobo.dev/rt-stream/)**

This repository holds the published installers under [Releases](https://github.com/rt-labs-dev/rt-stream-releases/releases) and is the place to [report a problem or suggest something](https://github.com/rt-labs-dev/rt-stream-releases/issues). The source code is not public.

This product uses the TMDB API but is not endorsed or certified by TMDB.

Part of [RT Labs](https://apps.rtobo.dev).
